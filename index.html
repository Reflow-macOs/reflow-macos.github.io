Live Editing Workflow

Modify your song while it plays. The new Reflow engine ensures zero interruptions. Drag sections, adjust notes, add effects—all in real time. Perfect for band sessions or solo practice.

Universal Import and Export

Open any Guitar Pro or PowerTab file instantly. Enter notes via MIDI keyboard. Export to MIDI, GP5, or WAVE. Full vector PDF for precise edits in Illustrator. Built-in library organizes everything.
